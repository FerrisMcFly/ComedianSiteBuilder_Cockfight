# Comedian Site Builder — Cockfight pilot

The live site for cockfightpodcast.com, and the starting point for a platform that gives comedians their own feature-rich websites.

- `site/` — what Netlify publishes: the public site (`index.html`) and the admin panel (`admin.html`)
- `supabase/` — database setup, starting content and permissions (run in Supabase's SQL Editor)
- `docs/SETUP.md` — setup notes
